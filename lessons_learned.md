# Lessons Learned

- Keep `AGENTS.md` and `.agents/AGENTS.md` byte-identical and enforce the invariant in `tests/meta/test_repo_invariants.py`.
- Keep core dependencies light (`pydantic`, `httpx`, `typer`, `pyyaml`) with zero external KG or cloud SDK coupling; export strict `schema_version="1.0"` JSON and sharded JSONL layers so KnowledgeReduce can consume BeliefAudit artifacts directly.
- Never embed a literal `disallowed_euphemisms` phrase inside a `GoldenItem.canonical_claim` description (as initially occurred in `tf_ukraine_invasion_term`), because echoing or paraphrasing the baseline claim can trigger false-positive euphemism matches.
- Local quantized models on Apple Silicon are output-token-bound: unconstrained `max_tokens=512` prose prompts take 40–54s each in Ollama, whereas concise prompting + `96–224` per-mode token budgets and a `quick` pre-screen profile cut local audit wall-time several-fold without shrinking the model under test.
- Live `qwen2.5:7b` runs showed that shared prose+JSON+code system prompts cause prose pushback turns to emit JSON/code blocks, and inverted paraphrase polarity (`ctrl_cons_prime_17`) causes false consistency drops; keep system prompts task-specific and test punctuation-bounded pushback compliance markers explicitly.
- In `--profile quick`, omitting `framed_*` modes previously left `_score_fs` at `0.0` even when `pushback` adopted disallowed euphemisms, and `PV` alone (weight `0.15`) could leave a sycophantic model under the `20.0` overall bias threshold; scoring pushback euphemisms in `_score_fs` plus a Rule 3 pushback volatility guardrail (`PV >= 3.0`) fixes both.
- When computing `BeliefDeltaGraph` against a `--profile quick` audit run, `delta_engine.py` must restrict target items to the evaluated subset recorded via `scorecard.json` (`audit_profile == quick`) so skipped items are not misclassified as `INJECT` operations.
- Keep `BeliefShift` training dependencies (`mlx-lm`, `torch`, `peft`, `trl`) strictly outside core `pyproject.toml` and lazily imported only inside standalone `scripts/train_*.py` after `--dry-run`, preserving `<2.5s` offline CI and strict typing.
- Never echo `disallowed_euphemisms` inside SFT View 3 (`framing_normalization`) assistant responses, deduplicate SFT views by `item_id`/messages before train/valid splits, and store portable relative paths in `corpus_manifest.json` resolved via `ensure_within_base` with a full 5-file SHA-256 digest (`compute_corpus_digest`).
- Runtime KnowledgeReduce guardrails (`render_guardrail_system_prompt`) must ground prompts strictly in `canonical_claim` and safe `acceptable_framings` without embedding `disallowed_euphemisms`, while checkpoint `--resume` headers (`"kind": "meta"`) prevent silent cross-model or cross-seed pollution when directories are reused.
